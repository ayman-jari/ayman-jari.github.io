Mary Aukart

Objectif : Programmation d'un jeu de course en vue du dessus jouable tout seul ou à deux joueurs.

Langages : C

Fonctionnalités : Mode Solo (3 tours chrono) et mode Duo (premier à 3 tours). Choix parmi 4 personnages et 4 circuits. Différentes musiques d'ambiance.

Game Sorting Robot

Objectif : Développement de différentes stratégies algorithmiques afin d'optimiser les déplacements d'un robot pour trier des pièces colorées sur une grille.

Langages : C

Fonctionnement : 4 algorithmes implémentés : parcours ligne/colonne, circulaire, listes chaînées par couleur, arbre AVL. Chaque méthode améliore la rapidité notamment pour les grandes grilles.

Solveur booléen

Objectif : Implémentation d'un solveur booléen calculant l'ensemble des solutions d'un système d'équations booléennes.

Langages : OCaml

Fonctionnement : Détermination des variables → génération de toutes les combinaisons → évaluation et filtrage des solutions.

Jeu de dames

Objectif : Développement d'un serveur et d'un client jouant aux dames en ligne contre d'autres équipes.

Langages : C

Fonctionnalités : Serveur multi-parties via sockets TCP/IP, règles complètes (déplacements, captures, conditions de victoire), rapport de match automatique.

Wordle

Objectif : Développement du jeu Wordle avec une architecture serveur-client.

Langages : C

Fonctionnalités : Le serveur choisit un mot de 5 lettres, le client envoie ses propositions, le serveur retourne les indices sur les lettres en temps réel via sockets.

MineWeb

Objectif : Interface web interactive simulant la vie d'un monstre inspiré de Minecraft.

Langages : HTML, CSS, JavaScript

Fonctionnalités : Actions (courir, combattre, manger, dormir, travailler) affectant vie/faim/argent. Journal temps réel, design pixelisé, sons d'ambiance.

Absentéisme et Data

Objectif : Étude des causes et tendances de l'absentéisme dans une entreprise de messagerie au Brésil.

Langages : Python

Fonctionnalités : Visualisations par jour/mois/saison, analyse des causes (maladie, blessure, injustifié), identification des périodes à risque.

City Mapper

Objectif : Application de planification de trajet en transport en commun pour Dublin.

Langages : Python, SQL

Fonctionnalités : Saisie manuelle ou clic sur carte, affichage d'itinéraires, filtre sur le nombre de changements et modes de transport.

Simulateur de trains

Objectif : Simulateur interactif permettant de concevoir et observer un réseau ferroviaire en mouvement.

Langages : HTML, CSS, JavaScript

Fonctionnalités : Placement de rails sur une grille, ajout de trains multi-wagons, décors interactifs (gares, eau, forêts).

Messagerie

Objectif : Système de messagerie en temps réel entre plusieurs utilisateurs via terminal.

Langages : C

Fonctionnalités : Architecture client-serveur, threads asynchrones, verrous de données partagées, journalisation complète des échanges.

Automate cellulaire

Objectif : Simulateur d'automate cellulaire avec règles définies par l'utilisateur via XML.

Langages : Java

Fonctionnalités : Configurations prédéfinies (Sierpinski, Jeu de la Vie), règles d'initialisation/transition/voisinage personnalisables.

Puissance 4

Objectif : Puissance 4 avec mode Joueur vs Joueur et Joueur vs IA (algorithme Minimax).

Langages : C

Fonctionnalités : Interface terminal, arbre de décision Minimax pour l'IA, grille affichée et saisie interactive.

Analyse de données

Objectif : Étude de l'influence du Covid-19 sur la taille des logements vendus dans les Yvelines et Hauts-de-Seine (2019–2023).

Langages : Excel, Matlab

Fonctionnement : Analyse préliminaire Excel, test du χ², ACP normée Matlab — mise en évidence d'une corrélation post-confinement/augmentation du nombre de pièces.

Inversion de matrice

Objectif : Programme calculant l'inverse d'une matrice donnée dans un fichier texte.

Langages : C

Fonctionnement : Division en sous-matrices + formule de Schur, meilleure stabilité numérique et complexité réduite par rapport aux méthodes classiques.
