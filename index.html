Mary Aukart

Objectif : Programmation d'un jeu de course en vue du dessus jouable tout seul ou à deux joueurs.

Langages : C

Fonctionnalités : Mode Solo (3 tours chrono) et mode Duo (premier à 3 tours). Choix parmi 4 personnages et 4 circuits. Différentes musiques d'ambiance.

Game Sorting Robot

Objectif : Développement de différentes stratégies algorithmiques afin d'optimiser les déplacements d'un robot pour trier des pièces colorées sur une grille.

Langages : C

Fonctionnement : 4 algorithmes implémentés : parcours ligne/colonne, circulaire, listes chaînées par couleur, arbre AVL. Chaque méthode améliore la rapidité notamment pour les grandes grilles.

Solveur booléen

Objectif : Implémentation d'un solveur booléen calculant l'ensemble des solutions d'un système d'équations booléennes.

Langages : OCaml

Fonctionnement : Détermination des variables → génération de toutes les combinaisons → évaluation et filtrage des solutions.

Jeu de dames

Objectif : Développement d'un serveur et d'un client jouant aux dames en ligne contre d'autres équipes.

Langages : C

Fonctionnalités : Serveur multi-parties via sockets TCP/IP, règles complètes (déplacements, captures, conditions de victoire), rapport de match automatique.

Wordle

Objectif : Développement du jeu Wordle avec une architecture serveur-client.

Langages : C

Fonctionnalités : Le serveur choisit un mot de 5 lettres, le client envoie ses propositions, le serveur retourne les indices sur les lettres en temps réel via sockets.

MineWeb

Langages : HTML, CSS, JavaScript

Fonctionnalités : Actions (courir, combattre, manger, dormir, travailler) affectant vie/faim/argent. Journal temps réel, design pixelisé, sons d'ambiance.

Asteroids

Objectif : Jeu de type Asteroids jouable dans le navigateur — contrôler un vaisseau spatial et survivre le plus longtemps possible face à des astéroïdes de plus en plus rapides et volumineux.

Langages : HTML, CSS, JavaScript, PHP

Fonctionnalités : Déplacement du vaisseau avec hitbox précise, spawn progressif des astéroïdes (fréquence et taille croissantes), gestion des vies, score en temps réel, meilleur score de session via PHP, fond étoilé animé en CSS, menu d'accueil avec profil joueur sauvegardé en localStorage.

Jouer à Asteroids

REPARTOUT

Objectif : Application web de gestion de SAV pour une entreprise de maintenance — suivi des clients, des machines et des interventions techniques.

Langages : Java (JAX-RS, JPA), JSP, SQL, HTML, CSS

Fonctionnalités : API REST complète (CRUD clients, machines, interventions), intégration d'un webservice de télé-diagnostic TELEDIAG générant automatiquement des interventions depuis des alertes machines, gestion des états d'intervention (en attente, en cours, réalisée, annulée), interface JSP multi-vues déployée sur serveur Jakarta EE.

Anneau-Étoile

Objectif : Résolution du problème d'optimisation combinatoire de l'anneau-étoile — trouver un réseau de stations reliées en cycle minimisant à la fois la distance des affectations et le coût du trajet en anneau.

Langages : Python (NumPy, SciPy, Matplotlib)

Fonctionnalités : Trois approches implémentées et comparées — heuristique constructive (p-médian + cycle glouton), métaheuristique d'amélioration par recherche locale, et résolution exacte par Programmation Linéaire en Nombres Entiers (PLNE) via SciPy. Génération de visualisations graphiques des solutions et comparaison des performances selon les paramètres p et alpha.

Dictionnaire multilingue

Objectif : Application graphique pour l'édition et la consultation de dictionnaires multilingues au format LIFT, destinée aux chercheurs en linguistique descriptive.

Langages : Java, JavaFX, XML

Fonctionnalités : Ouverture et parsing de fichiers LIFT (SAX), affichage des entrées lexicales sous forme de tableau, filtrage dynamique, formulaire d'édition complet, sauvegarde des modifications. Architecture MVC avec liaisons et observables JavaFX.

Gestion Poissonnerie

Objectif : Application desktop de gestion de commandes de plateaux de fruits de mer, développée pour la poissonnerie familiale pendant les fêtes de fin d'année (Noël → Nouvel An).

Langages : TypeScript, React, Node.js, Electron

Fonctionnalités : Saisie de commandes avec composition détaillée (huîtres, crevettes, crustacés, poissons — 30+ variétés), deux modes de préparation (plateau à dresser / simple emballage), suivi des statuts en temps réel, inventaire consolidé automatique, export PDF des commandes et génération d'étiquettes (6 par page A4).
